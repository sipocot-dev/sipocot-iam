# Security policy

## Reporting a vulnerability

Please **do not** open a public issue. Report privately via GitHub Security Advisories ("Report a vulnerability" on the repository's Security tab). Include steps to reproduce, impact, and any proof of concept. We aim to acknowledge within 3 business days and to ship a fix for confirmed high/critical issues within 14 days.

## Supported versions

Only the latest release on `main` receives security fixes.
